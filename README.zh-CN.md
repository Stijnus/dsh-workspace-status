# dsh-workspace-status · 工作区状态与置顶会话

[English](./README.md) · [中文](./README.zh-CN.md)

为 DeepSeek Harness 侧边栏增加两层能力：

1. **工作区状态标记**：在侧边栏的**工作区（文件夹）行**上显示彩色状态——等待你处理、正在运行、刚刚完成，由该工作区内的会话聚合而来。
2. **已置顶会话区**：通过 Harness 原生置顶操作置顶的会话，会从常规工作区分组中提取出来，显示在工作区列表上方的独立区域；按工作区分组，沿用原生工作区行的样式，并在行尾显示置顶图标。

侧边栏本来就会在每个会话行上显示状态点，但上方的文件夹行什么都没有。收起分组或滚动之后，就看不出里面是否还有等待审批、仍在运行的会话。本插件补上这一层，并把置顶会话集中到列表上方。

## 功能

### 工作区状态标记

| 标记 | 含义 | 颜色 |
|---|---|---|
| 实心点 | 有会话在等你：审批 / 计划评审 / 回答 | 琥珀 `--dsw-alias-state-warn-primary` |
| 旋转圆环 | 有会话或子代理正在运行 | 蓝 `--dsw-static-deepseek-450` |
| 实心点 | 有会话刚刚结束且尚未打开（1 小时提示窗口） | 绿 `--dsw-alias-state-success-primary` |

- 状态优先级与原生会话行一致：等待 > 运行 > 刚刚完成；一个工作区同时只显示一个主标记。
- 子代理的运行状态计入其父会话所在工作区；子代理行本身不产生标记。
- 已归档会话忽略；未分组会话落在「未分组」行。
- 标记固定在行尾时间戳的位置，不挤动标题；展开或收起都可见。
- 提供隐藏的无障碍描述（如「工作区状态：2 个运行中、1 个等待你处理 — api、web」）。

### 已置顶会话区

- 使用 Harness 原生置顶操作（会话行悬停按钮或 **…** 菜单）；置顶后无需重启即可出现在 **Pinned / 已置顶** 区域。
- 按工作区分组，每组沿用原生 34px 工作区行：文件夹图标、当前工作区蓝色高亮、折叠三角、圆角与计数。
- 每行显示实时状态点、相对时间、当前会话高亮，以及行尾的实心**置顶图标**；点击图标立即取消置顶，行会回到原工作区分组。
- Pinned 标题和各工作区分组都可折叠，折叠状态保存在浏览器本地。
- 区块限高并可独立滚动，不会把工作区列表挤走。
- 置顶集合来自 Harness 的 `pinnedSessionIds`（保存在 profile 的工作区注册表），重启后仍会显示同样的置顶会话与图标。
- 搜索不受影响：已置顶会话仍然出现在搜索结果中；常规分组列表则隐藏被提取的行。
- 常规列表中的工作区标题会保留（其「新会话」按钮仍可用），因此当某个工作区的会话全部被置顶时，常规列表里可能出现一个空分组，而会话显示在上方。

## 快速开始

```sh
dsh plugin --profile web add dsh-workspace-status
```

重启 Harness（或刷新 Web 界面）。工作区行会出现状态标记；置顶任意会话即可看到上方的置顶区域。

## 要求

- DeepSeek Harness `>=0.2.1-rc.2 <0.3.0-0`，Web 或桌面版。
- Node `>=22.18.0`（仅测试需要；无构建步骤）。
- 不修改 Host 行为、不提供设置项、不向模型注册工具或提示词；置顶状态使用 Harness 原生工作区置顶集合。

## 验证

1. 在某工作区运行会话并收起分组：工作区行尾出现蓝色圆环。
2. 在另一个工作区触发审批：即使展开，该行也显示琥珀点。
3. 让会话跑完但不打开：出现绿点，约一小时后消失。
4. 置顶任意会话：列表上方立即出现 Pinned 区，按工作区分组，行尾有置顶图标。
5. 再置顶另一个工作区的会话：出现第二个分组标题。
6. 点击行尾置顶图标取消置顶：该行立即从 Pinned 区消失并回到原工作区分组。
7. 重启 Harness：同样的置顶会话仍在，图标也仍显示。
